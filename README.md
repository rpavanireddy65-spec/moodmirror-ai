# 🧠 MoodMirror AI

### AI-Powered Facial Expression & Emotion Recognition

MoodMirror AI is an interactive web application that uses computer vision and deep learning-based facial expression recognition to analyze visible facial expressions from images or a live webcam feed.

The application provides an interactive dashboard showing the detected expression, confidence level, individual emotion probabilities, and a session-based emotion history.

---

## ✨ Features

- 📷 Upload an image for analysis
- 🎥 Live webcam emotion detection
- 🧠 AI-powered facial expression recognition
- 😊 Happy expression detection
- 😢 Sad expression detection
- 😡 Angry expression detection
- 😲 Surprised expression detection
- 😐 Neutral expression detection
- 📊 AI confidence percentage
- 📈 Individual emotion probability display
- 🕒 Emotion detection history
- 🔄 Start and stop webcam
- 🎨 Modern interactive interface
- 📱 Responsive design for different screen sizes
